# Contributing to SiteBrief

Thanks for considering a contribution!

## Ways to help

- Report a reproducible bug.
- Suggest a feature and explain the user problem it would solve.
- Improve keyboard navigation, screen-reader support, or mobile usability.
- Improve documentation or correct spelling and clarity.
- Submit a focused fix or enhancement.

## Before opening a pull request

1. Explain what problem the change solves.
2. Keep changes focused and easy to review.
3. Test the form, copy button, and text-file download in a modern browser.
4. Check that the layout works on both a narrow mobile screen and a desktop.
5. Do not add analytics, tracking, external requests, or collection of personal data without first discussing it in an issue.

## Reporting a bug

Include the browser and operating system you used, what you expected to happen, what happened instead, and steps to reproduce the issue. Do not include private or sensitive information.
