# SiteBrief

SiteBrief is a small, free, open-source web app that helps people turn rough website or app ideas into a clear project brief.

## Features

- Runs locally in a browser — no account or server required.
- Organizes a project's name, audience, goals, visual direction, and feature ideas.
- Generates a brief that can be copied or downloaded as a text file.
- Responsive layout for desktop and mobile.
- No analytics, tracking, or external dependencies.

## Run it

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Fill out the form and select **Generate my brief**.

You can also use GitHub Pages to host the static site publicly.

## Project status

This is an early community starter project. It has not yet been tested with a broad user group. Contributions, bug reports, accessibility feedback, and feature suggestions are welcome.
